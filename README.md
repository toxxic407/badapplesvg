# Bad Apple SVG
Bad Apple but its an SVG Animation
[Click here to view the Animation](https://toxxic407.github.io/badapplesvg/bad_apple.svg "Bad Apple but its an SVG Animation")

the bash script installs the dependencies (yt-dlp, ffmpeg and potrace), downloads the yt-video, extracts frames, converts those to svg and then splices them together to form a single svg animation
